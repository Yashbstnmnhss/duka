# duka-dbg

GDB 风格的 duka 交互式调试器,构建在 VM 的 debug 特性之上。

## 构建

```sh
cargo build -p duka-dbg
```

## 运行

```sh
duka-dbg [OPTIONS] <FILE> [-- <SCRIPT_ARGS>...]
```

- `-b, --break <LINE>` 启动前设置断点,可重复(如 `-b 3 -b 10`)。首条语句之前的整个启动量子不可暂停,初始断点必须用 `-b` 传入。
- `--no-break-on-error` 运行时错误不暂停,直接报错退出。
- `--` 之后的参数作为脚本参数透传。

## 命令

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `break <line>` | `b` | 在行上设置断点 |
| `delete <line>` | `d`, `del` | 移除断点 |
| `breaks` | `info` | 列出断点 |
| `continue` | `c` | 运行到下一个断点 |
| `next` | `n` | 单步(跳过调用) |
| `step` | `s` | 单步(进入调用) |
| `out` / `finish` | | 运行出当前帧 |
| `frames` | `bt`, `backtrace` | 显示调用栈,内层在前 |
| `frame [n]` | `f` | 选择帧,默认最内层 |
| `params` / `args` | | 显示所选帧的参数 |
| `locals` | `loc` | 显示所选帧的局部变量 |
| `list [line]` | `l` | 显示暂停处附近的源码 |
| `quit` | `q` | 退出 |
| `help` | `h` | 命令列表 |

空输入重复上一条单步命令;`Ctrl-C` 中断当前输入。

## 语义

- 断点与单步按**语句行**粒度触发:一条语句执行期间只暂停一次,循环体逐次迭代重新触发。
- 运行时错误默认暂停在出错语句上,输入 `c` 恢复后错误照常向外传播。
- 程序结束时打印返回值。
