## 快速开始

<Tabs>
    <TabItem label="dukao">

        ```sh
        dukao init my-kao
        cd my-kao
        dukao run
        ```

    </TabItem>
    <TabItem label="从源码构建">

        ```sh
        git clone https://github.com/Yashbstnmnhss/duka
        cd duka
        cargo build
        ```

    </TabItem>
    <TabItem label="REPL">

        ```sh
        duka-cli repl
        ```

    </TabItem>

</Tabs>

## 示例

```duka
function ticker(): (int, ...)
    yield(1)
    yield(2)
    return 0
end

local c: coroutine = spawn(ticker)
go(c)
```
