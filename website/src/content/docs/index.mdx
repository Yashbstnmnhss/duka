## Get started

<Tabs>
    <TabItem label="dukao">
    
        ```sh
        dukao init my-kao
        cd my-kao
        dukao run
        ```

    </TabItem>
    <TabItem label="From source">

        ```sh
        git clone https://github.com/Yashbstnmnhss/duka
        cd duka
        cargo build
        ```

    </TabItem>
    <TabItem label="REPL">

        ```sh
        duka-cli repl
        ```

    </TabItem>

</Tabs>

## Example

```duka
function ticker(): (int, ...)
    yield(1)
    yield(2)
    return 0
end

local c: coroutine = spawn(ticker)
go(c)
```
