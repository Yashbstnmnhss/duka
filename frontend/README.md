# Frontend for Duka

Duka's frontend includes:

- Basic lexer and lexer with preprocessor(lexer macro)
- Parser and custom bang handler (for `custom!{...}` `custom!(...)`)
- Adapters for desugaring and optimization
- Analyzers for control flow, scopes checking
- Type checker and evaluator for **type context**
- Basic IR generator
- Simple transpiler for debug using
